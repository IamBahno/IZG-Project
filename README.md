Project: Simple Graphics Card (GPU) Implementation
Subject: Computer Graphics Principles

Project Overview
The goal of this project is to implement a simple graphics card (GPU) and render models using various graphical pipeline stages. All necessary files for this project are located in the student/ directory. The key tasks include implementing the function gpu_execute in student/gpu.cpp, which simulates the functionality of the graphics card, and implementing functions for rendering models in student/drawModel.cpp
